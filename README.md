# 白龙娘 · ChatGPT 网页伴侣 V2.1

Chrome Manifest V3 扩展。内置本次生成的原创白龙娘高清角色素材（三张 576×1024 PNG，12 个姿势），无需另外导入。适用于 chatgpt.com 和 chat.openai.com。

## 安装
1. 解压 ZIP 至固定文件夹，不要直接打开 ZIP。
2. 打开 `chrome://extensions/`。关闭或移除 V1.0，避免两个角色重叠。
3. 开启开发者模式，点击「加载已解压的扩展程序」，选中包含 `manifest.json` 的 项目根目录。
4. 刷新已打开的 ChatGPT 网页。若未出现，可从 Chrome 拼图图标找到本扩展、开启显示并刷新。

## 使用
- 单击角色触发随机互动；双击打开对话与互动面板；拖动角色移动，位置会保存。
- 悬停显示工具栏：对话、缩放、设置、隐藏。隐藏后通过 Chrome 扩展图标恢复。
- 九个互动按钮：招呼、摸头、夸奖、逗逗、休息、唤醒、惊喜、思考、庆祝。
- 本地闲聊：预设台词和简单关键词匹配，不调用 AI。回车触发本地闲聊。
- 发给 ChatGPT：用户主动点击时将问题填入当前聊天输入框，尝试点击发送；不会覆盖已有草稿。若发送按钮无法识别，会提示手动发送。检测到新回答后显示最多 1800 字符的文本片段，完整内容留在 ChatGPT 聊天中。
- 设置：关闭动画、跟随鼠标、气泡、主动招呼、状态标签；也可以预览动画。默认自动跟随聊天状态。
- 自动互动：待机时偶尔打招呼（约100秒）；聊天时根据可见的停止生成按钮、回答文本变化等估计思考/回答/完成状态。

## 技术与限制
- 素材为 AI 生成并切分的 12 个姿势，采用 288×512 单帧画布，配合 CSS 动画。鼠标跟随使用左右朝向立绘、身体微倾与位置微调，不是真正的眼球骨骼跟踪或 Live2D。
- 只需 storage 权限及 ChatGPT 网页内容脚本，无第三方服务器和 API Key。不收集登录凭据，不向第三方上传聊天；只有用户主动点击发给 ChatGPT 才通过原网页发送文本。对话面板日志保存在当前页面内存，不写入扩展存储；设置保存在本地。
- 发送和状态识别依赖 ChatGPT 网页 DOM，未来网页改版可能需要更新选择器。无内部思考状态接口。
- V2.0 曾通过 Node.js 语法检查与 Chromium 模拟 ChatGPT DOM 测试；V2.1 整合版已做语法与素材尺寸检查，尚未重跑全部浏览器交互测试。真实 ChatGPT 登录页面在当前测试环境被浏览器策略阻止，未完成端到端验证。
- 如需要排障：打开扩展管理页查看错误，确认旧版已禁用并刷新 ChatGPT。

## 更新
若从 V2.0 升级，将本项目文件覆盖原扩展目录，在扩展管理页重新加载后刷新 ChatGPT。
